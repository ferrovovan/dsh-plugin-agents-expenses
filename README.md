# dsh-rashod-live — «Расход-живой»

**Статус:** 0.1.0 — заготовка, по умолчанию выключена (`enabled: false`).
**Боль (AGENTS.md I.2):** живого счётчика токенов нет; расход известно
только постфактум из журналов; правило «превышение 2× — стоп» держится
в голове координатора.

## Что делает

Слушает журнал сессий харнесса; на закрытии хода меряет сессию сервисом
`tokenMeter` и дописывает **оценочную** строку JSONL в промежуточный файл.
Файл — вход для `tools/расход` (занос в `РАСХОД.db` — только якорем, П-69;
плагин в БД не пишет).

## Конфиг (строка в cordis.patch.yml)

| поле | смысл |
|---|---|
| `file` | путь промежуточного JSONL-журнала |
| `enabled` | рубильник; `false` — плагин молчит |
| `task` | индекс задачи в строке (`П-NN`, `D-NN`, `—`) |
| `model` | метка модели, если харнесс её не отдаёт |

## Установка / разработка

- Установка: plugin manager → `install_bundle` с абсолютным путём репо.
- После правок: `make check`, переустановка; замена кода может требовать
  рестарт DSH.
- Чек-лист доводки до 0.2.0 — в `INTERNAL.md`.

## Честность чисел

Строка содержит `kind: "оценка"` и `source: "tokenMeter"`. Замером из
журнала DSH это не является, пока не закрыт неизвестный №2 (точный usage).
