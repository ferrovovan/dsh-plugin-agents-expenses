# ARCH — контракты плагина (меняет только совет через комнату; метка ARCH-CHANGE)

1. Единственный выход плагина — append в `config.file`. Никаких других
   записей, сети, БД.
2. Источник истины — журнал сессии + `ctx.tokenMeter`; память плагина не
   копит состояние между сессиями.
3. Формат строки (v1): `{ts, sessionId, kind, source, totalTokens,
   surfaceTokens, baseline, pressureTokens, contextWindow, task, model}`.
   Изменение формата = stateVersion/мажор формата + запись в INTERNAL.md;
   удалённых полей не делать — `tools/расход` читает v1.
4. Прослушивание — только существующие события (`session/event`); новых
   типов в журнал сессии не добавляем (запрет харнесса).
5. Производительность: один измерительный вызов на закрытие хода; при
   доводке — перевод на `sessionProjections` (чистая свёртка вместо
   слушателя), контракт строки не меняется.
