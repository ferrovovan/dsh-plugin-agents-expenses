# SOUL плагина «Расход-живой»

1. Число без метки природы — не число: каждая строка несёт `kind`
   (`оценка`/`замер`) и `source`.
2. В РАСХОД.db не писать никогда — там якорь, валидация и транзакция.
   Плагин — только голос в промежуточный файл.
3. Сбой замера не имеет права тронуть сессию: тихо в лог, живём дальше.
4. Рубильник `enabled` уважаем: включён — пишем, выключен — не делаем
   ничего, даже «мелкую строчку для полноты».
